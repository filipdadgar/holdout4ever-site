# holdout4ever-site

Static website for Holdout4Ever at https://holdout4ever.dadgar.se, served by Cloudflare Pages.

- No build step. Cloudflare Pages serves the repository root as is.
- Pages: `index.html` (home and beta link), `privacy.html` (App Store Connect Privacy Policy URL), `support.html` (App Store Support URL).
- Colours follow the game's approved shell palette (set 1, "warm sand").
- Only public material belongs here: no keys, no IDs, no personal data beyond the published contact address.

Changes go live when they are merged to `main`.
